## ∞ Meta Model API Hackathon Architecture (`https://api.meta.ai/v1`)

**OceanEye (Meta Hackathon Edition)** integrates **four native foundation models from the Meta Model API (`https://api.meta.ai/v1`)** with Sentinel-1 C-Band Synthetic Aperture Radar (SAR), AIS telemetry, and the **LAYA Neuro-Symbolic & Ed25519 Cryptographic Custody Engine** to detect, visually reconstruct, segment, and prosecute Illegal, Unreported, and Unregulated (IUU) dark vessels in the South Atlantic (Mile 201 / Blue Hole):

| :--- | :--- | :--- | :--- | :--- |
| **1. Flagship Deep Reasoning** | **`muse-wonder-1.0`** | `POST /v1/chat/completions` | Synthesizes court-ready UNCLOS / Ley 24.922 forensic dossiers & fleet-wide *Reefer Rendezvous* intelligence, verified by `NeuroSymbolicValidator`. | **12 Dark Vessel Dossiers + Fleet Intel (`49,293` tokens / `98.75%` adherence -> `100%` post-sanitization)** |

| **3. Satellite Target Synthesis** | **`muse-image-1.0`** | `POST /v1/images/generations` & `/v1/responses` | Synthesizes top-down nadir satellite reconstructions of dark vessels from their physical radar cross-section (RCS in dB), length, beam, and wake. | **5 Priority Dark Vessels reconstructed (`1600×1600` frames)** |
| **4. Lossless Hull Segmentation** | **`sam-3.1`** | `POST /v1/files` + `POST /v1/responses` | Performs pixel-accurate hull & wake segmentation (`mask_encoding: lossless`), extracting exact `[x1, y1, x2, y2]` bounding boxes and lossless RLE masks. | **5/5 Lossless RLE Masks & Hull Bounding Boxes extracted** |

### New Meta Model API Endpoints in FastAPI (`backend/app/api/routes_sar.py`)
- `POST /api/v1/sar/meta/forensic-dossier/{target_id}` — Runs `muse-wonder-1.0` + `NeuroSymbolicValidator` (0.00% numerical hallucination) + `LAYA Ed25519` signature.
- `POST /api/v1/sar/meta/reconstruct-and-segment/{target_id}` — Runs `muse-image-1.0` → uploads frame to `POST /v1/files` (`purpose=user_data`) → executes `sam-3.1` on `POST /v1/responses` (`mask_encoding=lossless`).
- `GET /api/v1/sar/meta/telemetry` — Returns real-time token, reasoning-token, image, and SAM 3.1 segmentation counters.
- Pre-computed certified benchmark artifact: `backend/ml/meta_muse_sam31_benchmark_2026.json` & `frontend/data/meta_muse_sam31_benchmark_2026.json` (generated by `scripts/run_meta_hackathon_benchmark.py`).

Está diseñada para detectar, correlacionar y tipificar jurídicamente la pesca ilegal, no declarada y no reglamentada (INDNR / IUU Fishing) en el Atlántico Sur y el Agujero Azul (Milla 201), aportando evidencia pericial con cadena de custodia criptográfica SHA-256 ante el Régimen Federal de Pesca (Ley 24.922).

## 🛠️ Componentes Clave

- **Base de Datos Espacio-Temporal**: PostgreSQL + TimescaleDB (Supabase) con retención automática de 90 días para millones de posiciones AIS.
- **Worker 24/7 Ininterrumpido**: Proceso independiente que ingiere transmisiones AIS de la ZEE Argentina, calcula heurísticas de riesgo en tiempo real y genera alertas inmediatas.
- **Motor de IA (Artificial AI)**: Sistema multi-modelo con tolerancia a fallos para análisis tácticos en lenguaje natural, reportes de inteligencia y chatbot conversacional.
- **Enriquecimiento GFW**: Integración directa con Global Fishing Watch API para correlación de eventos de loitering, vacíos AIS (dark vessels) y visitas a puerto.
